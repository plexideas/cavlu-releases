# Cavlu

Нативное приложение macOS для исправления текста, набранного в неверной русской или английской раскладке. Работает в строке меню, обрабатывает ввод локально и не отправляет его в сеть.

**macOS 14+ · Apple Silicon и Intel · Universal**

## Установка через Homebrew

На новом Mac подключите tap один раз:

```sh
brew tap plexideas/cavlu
brew install --cask cavlu
open -a Cavlu
```

После подключения tap для установки достаточно `brew install --cask cavlu`. Xcode и сборка из исходников не нужны. Приложение устанавливается в `/Applications/Cavlu.app`.

В **Настройки → Основные → Значок в строке меню** можно выбрать раскладку, флаг или «Иконка приложения». Монохромный логотип автоматически получает светлый или тёмный цвет от macOS в зависимости от фона строки меню. На паузе рядом с логотипом появляется маленький знак паузы.

Если ваша версия Homebrew сообщает `untrusted tap`, один раз выполните `brew trust --cask plexideas/cavlu/cavlu`, затем повторите установку. Это разрешение только для данного cask; защита macOS не отключается.

Если macOS блокирует первый запуск, используйте штатное «Всё равно открыть» в «Системные настройки → Конфиденциальность и безопасность». Текущие пакеты имеют ad-hoc подпись, без нотарификации Apple. Не отключайте Gatekeeper. Предоставьте Cavlu «Универсальный доступ» и «Мониторинг ввода»; автоисправление по умолчанию включено. Временная пауза доступна в строке меню.

Для ручного исправления наберите `ghbdtn`, затем нажмите и отпустите Option. Для работы нужны английский (US/ABC) и русский источники ввода. Терминалы и нестандартные редакторы имеют ограничения; проверьте работу в своих приложениях, при необходимости используйте паузу.

## Обновления

Откройте **Настройки → О программе → Проверить обновления…**. Здесь видны версия и сборка приложения, результат последней проверки и история выпусков. Найденное обновление можно загрузить и установить через окно обновления. Подписи appcast и ZIP проверяются до распаковки; настройки сохраняются. Проверка доступна также в меню приложения. Автообновление отключено: нет фоновых проверок, автоматических загрузок и перезапуска по бездействию.

Ad-hoc сборки могут потребовать повторного разрешения Accessibility/Input Monitoring после обновления. Подпись обновлений не заменяет Apple Developer ID и не обходит защиту macOS. Сервер GitHub получает сетевые метаданные запросов обновления, но не набранный текст, правила или настройки; профилирование выключено.

Альтернативное обновление и удаление:

```sh
brew update
brew upgrade --cask --greedy cavlu
brew uninstall --cask cavlu
```

Удаление с `--zap` также удаляет настройки, правила и обученные исключения. Перед удалением завершите Cavlu и отключите автозапуск.
